# Track Record

Personal portfolio concept built with React + TypeScript + Vite and a 3D turntable scene using React Three Fiber.

## Stack

- React + TypeScript + Vite
- Three.js via `@react-three/fiber` and `@react-three/drei`
- `@react-spring/three` for vinyl motion in 3D
- Framer Motion for content panel transitions

## Features in this scaffold

- 3D turntable scene with lighting and camera controls
- Hover animations for vinyls in a stack
- Click-to-load vinyl animation onto the record player
- Spinning loaded vinyl and synchronized content panel updates
- Starter generated label assets under `public/assets/labels`

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
